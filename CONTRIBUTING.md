# Contributing

Thanks for helping. The general rules are in the main repository:
https://github.com/openagentix/openagentix/blob/main/CONTRIBUTING.md

For this site:

- Sign off every commit with `git commit -s` (DCO).
- Run `pnpm test:all` before you open a pull request.
- Every factual claim on the site must be backed by
  [docs/diary/what-works.md](https://github.com/openagentix/openagentix/blob/main/docs/diary/what-works.md)
  in the main repository. If it is not there, do not claim it.
- Keep the text plain and short. No hype words, no em dashes, no tracking.
